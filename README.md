# 📦 Simple Java Stock System
A simple inventory management system built in Java using console input. This project was created for learning purposes while studying Java basics such as arrays, loops, and switch-case logic.

🚀 Features
Add products to inventory
Remove products by position
List all products
Increase product quantity
Decrease product quantity
Basic validation to avoid invalid positions and stock errors

🧠 How it works
The system uses:

Two arrays:
 - String[] products
 - int[] quantity
 - A while loop to keep the menu running
 - A switch-case to handle user options

Each product is stored by position (index).

📋 Menu Options
1 - Add product  
2 - Remove product  
3 - List all products  
4 - Add quantity  
5 - Remove quantity  
6 - Exit  

🛠 Technologies used
 - Java
 - Scanner (for input)
 - Arrays
 - Console application

📌 Learning purpose
This project was made to practice:
 - Arrays manipulation
 - Loops (while, for)
 - Switch-case logic
 - Basic input handling in Java
